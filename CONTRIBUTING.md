# Como Contribuir para o 1NXXITER HUB

Agradecemos o seu interesse em contribuir para o **1NXXITER HUB**! Este documento fornece diretrizes para garantir que o processo de contribuição seja o mais tranquilo possível.

## 🐛 Reportando Bugs

Se você encontrar algum bug ou comportamento inesperado, por favor:

1. **Pesquise primeiro**: Verifique se o bug já não foi relatado na aba de Issues.
2. **Crie uma Issue**: Use o template de Bug Report disponível e forneça o máximo de detalhes possível, incluindo passos para reproduzir, comportamento esperado e comportamento atual.
3. **Imagens/Vídeos**: Adicione screenshots ou vídeos sempre que possível para facilitar o entendimento.

## ✨ Sugerindo Novas Funcionalidades

Adoramos novas ideias! Para sugerir uma funcionalidade:

1. **Pesquise**: Veja se alguém já sugeriu algo parecido.
2. **Crie uma Issue**: Use o template de Feature Request para detalhar o que você gostaria de ver e qual o problema essa funcionalidade resolve.

## 🛠️ Contribuindo com Código

Se você deseja enviar uma melhoria de código:

1. **Faça um Fork**: Crie um fork do repositório para a sua conta.
2. **Crie uma Branch**: Crie uma nova branch com um nome descritivo (ex: `feature/novo-aimbot` ou `fix/crash-no-esp`).
3. **Siga a Arquitetura**: Mantenha o padrão modular estabelecido. Se criar algo novo, coloque no diretório adequado (`Core`, `Features` ou `Interface`).
4. **Teste seu Código**: Certifique-se de que sua alteração não quebra funcionalidades existentes e que foi testada no Roblox.
5. **Crie o Pull Request**: Faça o PR detalhando suas alterações, o porquê de tê-las feito e referencie issues caso estejam relacionadas.

## 📄 Estilo de Código (Lua)

* Use `local` para variáveis sempre que possível.
* Prefira funções locais (`local function nome()`) em vez de globais.
* Mantenha o código limpo, comentado onde houver lógica complexa e use indentação com espaços (4 espaços).
* Aproveite a estrutura de classes e serviços que o 1NXXITER possui em `Core/`.

Obrigado por ajudar a tornar o **1NXXITER HUB** ainda melhor! 🚀
